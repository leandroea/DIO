# Desafio: Gerenciando Instâncias EC2 na AWS

Repositório de anotações e insights sobre gerenciamento de instâncias Amazon EC2, desenvolvido como entregável do laboratório de consolidação de conhecimentos em AWS.

## Objetivo

Consolidar conhecimentos em:
- Visualização e seleção de AMIs (Amazon Machine Images)
- Execução (launch) de instâncias EC2
- Conexão a instâncias (Windows/Linux)
- Parar, encerrar e configurar comportamento de desligamento

## Estrutura do Repositório

```
├── README.md                 # Este arquivo
├── anotacoes/
│   ├── 01-amis-e-visualizacoes.md   # AMIs e visualizações no AWS Explorer
│   ├── 02-executar-instancia.md     # Passo a passo para launch
│   ├── 03-conectar-instancia.md     # RDP e acesso remoto
│   └── 04-parar-e-encerrar.md       # Stop, Terminate e shutdown behavior
└── recursos.md              # Links e referências úteis
```

Utilize as anotações em `anotacoes/` como material de apoio para estudos e futuras implementações de instâncias EC2.
