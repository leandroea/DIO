# Bootcamp NTT DATA - Data Analysts & Engineers

## 📌 Introdução
Este bootcamp gratuito da **NTT DATA** é voltado para quem deseja se destacar em vagas de **Analista de Dados** e **Engenheiro de Dados**.  
Durante o programa, você aprenderá desde os fundamentos da linguagem **Python** até o domínio no **tratamento de dados** e criação de **dashboards com Power BI**, seguindo práticas utilizadas dentro da própria NTT DATA.

O objetivo é aumentar suas chances de contratação nas vagas oferecidas pela empresa e fortalecer seu portfólio com projetos reais.

---

## 🎯 Objetivos
- Aprender Python aplicado ao contexto de dados.  
- Dominar técnicas de **ETL, Data Warehousing e Data Visualization**.  
- Construir dashboards profissionais com **Power BI**.  
- Desenvolver projetos práticos que podem ser incluídos no portfólio.  
- Preparar-se para processos seletivos da NTT DATA e do mercado de tecnologia.

---

## 📚 Atividades do Bootcamp

### 1. Courses
- Aulas em vídeo curtas e objetivas.  
- Cada curso apresenta um conteúdo específico, facilitando o aprendizado no seu ritmo.  
- Ao final de cada módulo, há uma avaliação para consolidar o conhecimento.

### 2. Mentoring (Live)
- Sessões de mentoria ao vivo com especialistas da área.  
- Espaço para tirar dúvidas, discutir aplicações práticas e receber orientação direta.  
- Oportunidade de networking e troca de experiências com profissionais atuantes no mercado.

### 3. Code Challenge
- Desafios práticos de programação.  
- Aplicação dos conceitos aprendidos em problemas reais.  
- Desenvolvimento de raciocínio lógico e habilidades técnicas.

### 4. Project Challenge
- Projetos completos que integram os conteúdos estudados.  
- Criação de soluções para problemas reais de negócio.  
- Entregáveis que podem ser adicionados ao seu portfólio para destacar suas habilidades.

---

## 🚀 Como Participar
1. Inscreva-se gratuitamente no bootcamp.  
2. Acompanhe as aulas e participe das mentorias ao vivo.  
3. Resolva os **Code Challenges** para praticar.  
4. Conclua os **Project Challenges** e adicione-os ao seu portfólio.
