# 🚀 Desafio DIO - Playground do Azure OpenAI

Este projeto foi desenvolvido como parte de um desafio da [Digital Innovation One (DIO)](https://www.dio.me/), com o objetivo de **explorar o Playground do Azure OpenAI**, gerar conteúdos e compreender as diferentes configurações e parâmetros disponíveis.

⚠️ **Aviso Importante**:  
Este desafio tem **finalidade exclusivamente educacional**. O uso das ferramentas deve ser feito em ambientes controlados e com responsabilidade.

---

## 📂 Objetivo do Projeto

- Utilizar o **Playground do Azure OpenAI** para gerar textos, respostas e conteúdos criativos.  
- Experimentar diferentes **configurações e parâmetros** do modelo.  
- Documentar os resultados obtidos e reflexões sobre o uso da ferramenta.  

---

## ⚙️ Configurações e Parâmetros Testados

Durante o desafio, foram explorados os seguintes aspectos do Playground:

- **Modelos disponíveis**: escolha de diferentes modelos de linguagem.  
- **Temperatura**: controle da criatividade e variação das respostas.  
- **Top-p (nucleus sampling)**: ajuste da diversidade de saída.  
- **Max tokens**: limite de tamanho das respostas geradas.  
- **Stop sequences**: definição de pontos de parada para o texto.  
- **Frequency penalty**: redução de repetições.  
- **Presence penalty**: incentivo à introdução de novos tópicos.  

---

## 🛠️ Exemplos de Uso

### 1. Geração de Texto Criativo
Configuração com **temperatura alta (0.9)** para respostas mais criativas e variadas.

### 2. Respostas Técnicas
Configuração com **temperatura baixa (0.2)** para maior precisão e consistência.

### 3. Controle de Comprimento
Definição de **max tokens** para limitar ou expandir a resposta.
