# Desafio: Gerar artigo técnico — "Inteligência Artificial com Python"

---

## 🔎 Visão geral
Este repositório reúne o trabalho realizado para o desafio de **gerar um artigo técnico** sobre *Inteligência Artificial com Python* usando prompts e ferramentas de I.A.. O objetivo foi produzir um texto didático e prático (800–1.200 palavras), com exemplos em Python e formatação pronta para publicação.

## 🎯 Objetivo do desafio
- Gerar títulos (headlines) e opções para publicação;
- Seguir a estrutura e regras definidas em um prompt (`prompt.md` com seções obrigatórias, tom didático, exemplos de código, etc.);
- Gerar um artigo técnico acessível para iniciantes em IA;

## 📁 Estrutura do repositório
- `INSTRUCOES.md` — Informações adicionais, assets e referência do projeto.
- `headlines.txt` — Conjunto de sugestões de títulos/headlines.
- `prompt.md` — Prompt usado para gerar o conteúdo (regras, estrutura e restrições).
- `artigo.md` — **Artigo final** (formatado em Markdown por comodidade).

## ⚙️ Como reproduzir
1. Use um título de `headlines.txt` (ou peça novas variações ao modelo).
2. Abra `prompt.md` e copie o prompt para a ferramenta de geração (ex.: ChatGPT).
3. Gere o conteúdo.
4. Salve o resultado em `artigo.md` e aplique formatação (títulos, listas, blocos de código).
5. Gere imagens ilustrativas em `Lexica.art` e finalize o layout em PowerPoint/Editor.

## 🧰 Ferramentas utilizadas
- **ChatGPT** — geração do texto e headlines
- **Lexica.art** — imagens (opcional)
- **PowerPoint / Editor de texto** — diagramação e banners
