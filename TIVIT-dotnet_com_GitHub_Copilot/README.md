# 🚀 TIVIT - .Net com GitHub Copilot

## 📌 Descrição
Este repositório foi criado para organizar e documentar minha jornada no **TIVIT - .Net com GitHub Copilot**, oferecido pela **DIO** em parceria com a **TIVIT**.  
O objetivo é dominar o desenvolvimento back-end criando **APIs REST robustas**, aplicando **Inteligência Artificial** para acelerar o desenvolvimento, com foco em **boas práticas, testes automatizados, segurança** e **integração com bancos de dados utilizando Entity Framework**.

O conteúdo é totalmente alinhado com o dia a dia de desenvolvedores back-end e conta com mentorias dos experts da TIVIT, além da aplicação prática do **GitHub Copilot** em todo o ciclo de desenvolvimento.

---

## 🎯 Objetivos do Bootcamp
- Criar APIs REST escaláveis e seguras com **.NET e C#**.
- Aplicar **Entity Framework** para integração com bancos de dados.
- Utilizar **testes automatizados** e boas práticas de desenvolvimento.
- Incorporar **Inteligência Artificial** para acelerar o processo de codificação.
- Construir projetos práticos para compor o portfólio e destacar habilidades.

---

## 🗂️ Estrutura do Repositório
- `Mentorships/` → Anotações e materiais das mentorias ao vivo.
- `CodeChallenges/` → Exercícios e desafios de código realizados durante o bootcamp.
- `ProjectChallenges/` → Projetos práticos desenvolvidos para o portfólio.
- `README.md` → Documento principal com descrição do bootcamp.

---

## 📊 Atividades
- **Mentorships (Live):** Momentos de inspiração com experts de empresas inovadoras, com interação e perguntas sobre carreira e tecnologia.  
- **Code Challenge:** Exercícios práticos para aplicar o conhecimento adquirido nas aulas.  
- **Project Challenge:** Desenvolvimento de projetos completos para compor o portfólio.  
- **Ranking:** Sistema de pontuação com prêmios exclusivos, baseado em interações nos fóruns, quizzes e qualidade do código.

---

## 🛠️ Ferramentas de Aprendizado
- **Forum:** Espaço para interação e dúvidas técnicas com a comunidade.  
- **Rooms:** Ambiente para networking e troca de experiências com outros participantes.  
- **Enrolled:** Lista de participantes que estão na mesma jornada educacional.  
- **Certificate:** Certificados de conclusão para cada etapa do bootcamp.
