# 💳 Validador de Bandeiras de Cartão de Crédito

## 📌 Descrição
Este projeto foi desenvolvido como parte do desafio da **DIO (Digital Innovation One)**.  
O objetivo é criar uma aplicação simples capaz de identificar a **bandeira de um cartão de crédito** (Visa, MasterCard, etc.) com base no número informado.  

Durante o desenvolvimento, utilizamos o **GitHub Copilot** como assistente de codificação, explorando como a inteligência artificial pode acelerar o processo, sugerir trechos de código e aumentar a produtividade.
