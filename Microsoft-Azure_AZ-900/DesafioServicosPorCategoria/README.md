# 📘 Microsoft Azure - Localizando Serviços por Categoria

## Resumo do Tema

O Microsoft Azure organiza seus serviços em categorias para facilitar a navegação e o entendimento da plataforma. Essa estrutura ajuda usuários iniciantes e avançados a localizar rapidamente os recursos necessários para suas soluções em nuvem.

Algumas das principais categorias de serviços incluem:

    Computação: Máquinas virtuais, funções serverless, Kubernetes.

    Rede: VPN, balanceadores de carga, DNS, firewalls.

    Armazenamento: Blob Storage, Disk Storage, File Storage.

    Banco de Dados: SQL Database, Cosmos DB, PostgreSQL, MySQL.

    IA e Machine Learning: Cognitive Services, Azure Machine Learning.

    Segurança e Identidade: Azure Active Directory, Key Vault.

    Ferramentas de Gerenciamento: Monitor, Advisor, Cost Management.

Essa organização é essencial para quem está iniciando, pois permite explorar os serviços de forma estruturada e entender como cada recurso se encaixa em soluções reais.

# 📑 Guia Passo a Passo – Primeiros Passos no Azure

## 1. Acessando o Portal

    Entre em https://portal.azure.com.

    Faça login com sua conta Microsoft.

## 2. Explorando o Menu Principal

    No painel lateral esquerdo, você encontrará:

        Home: visão geral do portal.

        Todos os serviços: lista completa de serviços organizados por categoria.

        Criar um recurso: atalho para adicionar novos serviços.

## 3. Localizando Serviços por Categoria

    Clique em Todos os serviços.

    Use a barra de pesquisa ou navegue pelas categorias (Computação, Rede, Armazenamento, etc.).

    Cada categoria apresenta os serviços relacionados, com ícones e descrições.

## 4. Criando um Recurso

    Clique em Criar um recurso no menu lateral ou na página inicial.

    Escolha a categoria desejada (exemplo: Computação → Máquina Virtual).

    Configure os parâmetros básicos:

        Nome do recurso.

        Região (datacenter).

        Sistema operacional e tamanho da máquina.

    Clique em Revisar + Criar e depois em Criar.

## 5. Gerenciando Recursos

    Após a criação, acesse Recursos no menu lateral.

    Lá você pode visualizar, configurar e monitorar os serviços ativos.

    Utilize o Azure Monitor para métricas e alertas.
