# 💊 Projeto Farmácia Virtual na AWS

Este projeto tem como objetivo conceber e projetar uma **plataforma virtual para uma farmácia fictícia**, utilizando a infraestrutura da **Amazon Web Services (AWS)**.  
A proposta é enfrentar desafios semelhantes aos encontrados no mundo real, aprofundando o conhecimento em serviços de nuvem e aplicando conceitos teóricos em um cenário prático e dinâmico.

---

## 🎯 Objetivos do Projeto
- Criar uma arquitetura em nuvem para suportar uma farmácia virtual.  
- Utilizar serviços da AWS para garantir **escalabilidade, segurança e redução de custos**.  
- Documentar o processo de implementação em formato de relatório.  
- Demonstrar habilidades práticas em **Cloud Computing** e **AWS** para portfólio.

---

## 🏗️ Arquitetura Proposta
A solução foi dividida em três etapas principais, cada uma utilizando um serviço da AWS:

1. **Amazon S3**  
   - Armazenamento escalável e seguro de dados.  
   - Utilizado para centralizar arquivos da farmácia (receitas, relatórios, documentos).  

2. **Amazon RDS**  
   - Banco de dados relacional gerenciado.  
   - Utilizado para armazenar informações de clientes, produtos e transações.  

3. **Amazon EC2**  
   - Hospedagem de aplicações e serviços.  
   - Utilizado para disponibilizar a plataforma virtual da farmácia, garantindo escalabilidade.  

---

## ⚙️ Tecnologias Utilizadas
- **AWS Cloud**  
- **Amazon S3** (armazenamento)  
- **Amazon RDS** (banco de dados)  
- **Amazon EC2** (hospedagem de aplicação)  
- **Markdown** para documentação  

---

## 🚀 Como Reproduzir
1. Criar uma conta na AWS.  
2. Configurar os serviços conforme descrito no relatório (`relatorio.md`).  
3. Implementar a aplicação da farmácia fictícia em uma instância EC2.  
4. Testar a integração entre EC2, RDS e S3.  

---

## 📌 Benefícios Esperados
- Redução de custos com infraestrutura física.  
- Maior escalabilidade e disponibilidade dos serviços.  
- Aumento da segurança e confiabilidade dos dados.  
- Documentação clara para replicação e aprendizado.
