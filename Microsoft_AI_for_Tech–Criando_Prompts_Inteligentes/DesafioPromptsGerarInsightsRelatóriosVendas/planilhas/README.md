# Planilhas Utilizadas

Esta pasta contém os dados de vendas utilizados para gerar insights com o auxílio de prompts e ferramentas de IA.

## Arquivos

### `relatorio_vendas.csv`

Relatório de vendas de **janeiro/2025** com as seguintes colunas:

| Coluna        | Descrição                          |
|---------------|------------------------------------|
| Data          | Data da venda (YYYY-MM-DD)         |
| Vendedor      | Nome do vendedor                   |
| Região        | Região do Brasil (Sul, Sudeste, Nordeste) |
| Produto       | Nome do produto                    |
| Quantidade    | Quantidade vendida                 |
| Valor_Unitário| Preço unitário (R$)                |
| Valor_Total   | Valor total da venda (R$)          |
| Canal         | Canal de venda (Loja ou Online)    |

**Produtos no relatório:** Notebook, Monitor, Teclado, Mouse, Webcam.

**Uso:** O arquivo pode ser aberto no Excel, Google Sheets ou importado em Power BI. Para usar com IA, copie o conteúdo ou envie o arquivo conforme suportado pela ferramenta (ex.: anexo no ChatGPT/Copilot).
