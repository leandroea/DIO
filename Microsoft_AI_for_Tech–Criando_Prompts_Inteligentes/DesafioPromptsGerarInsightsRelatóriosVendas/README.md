# Desafio: Prompts para Gerar Insights em Relatórios de Vendas

Projeto desenvolvido no contexto do **Microsoft AI for Tech – Criando Prompts Inteligentes** (DIO). O objetivo é explorar o uso de **prompts** com ferramentas de inteligência artificial para analisar relatórios de vendas e extrair **insights valiosos** para a tomada de decisão.

---

## Objetivos do Projeto

- **Gerar insights estratégicos** a partir de dados de vendas usando IA
- **Aplicar conceitos** de prompts estruturados em um ambiente prático
- **Documentar processos** técnicos de forma clara e estruturada
- **Utilizar o GitHub** para compartilhamento de documentação técnica

---

---

## Como Utilizar Este Projeto

1. **Planilhas**: Acesse a pasta `planilhas/` para os dados de vendas. O arquivo CSV pode ser aberto no Excel, Google Sheets ou importado em ferramentas de BI.

2. **Prompts**: Consulte `prompts/prompts_aplicados.md` para os prompts utilizados na análise. Você pode replicá-los em ferramentas como ChatGPT, Copilot ou Azure OpenAI.

3. **Insights**: Os insights gerados pela IA com base nos dados e nos prompts estão em `insights/insights_obtidos.md`.

4. **Metodologia**: O documento `docs/processo_analise.md` descreve o fluxo de trabalho e boas práticas para repetir o processo com seus próprios dados.

---

## Ferramentas Sugeridas

- **IA para análise**: ChatGPT, Microsoft Copilot, Azure OpenAI, ou outros assistentes com capacidade de interpretar tabelas e texto.
- **Planilhas**: Microsoft Excel, Google Sheets.
- **Versionamento**: Git e GitHub para manter a documentação e os dados organizados.
