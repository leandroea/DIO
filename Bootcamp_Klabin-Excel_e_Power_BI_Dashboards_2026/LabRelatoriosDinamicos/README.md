# 📊 Projeto de Relatório com Parâmetros e Storytelling

## 📌 Descrição
Este projeto foi desenvolvido como parte do desafio da **DIO (Digital Innovation One)** no módulo de **Visualização de Dados**.  
O objetivo é criar visuais interativos utilizando parâmetros, aplicando técnicas de storytelling para apresentar os dados de forma clara e envolvente, como se fosse uma entrega para um cliente.

---

## 🎯 Objetivos do Desafio
- Utilizar o relatório do desafio anterior como base.
- Criar **dois visuais** com parâmetros:
  - **Primeira visão**: parâmetro com base em **categorias**.
  - **Segunda visão**: parâmetro com base em **valores** (ex.: profit, sales, etc.).
- Manter a mesma **estilização** do relatório original.
- Criar uma **história** que guie a interpretação dos dados, evitando apenas “jogar” os visuais.
- Estruturar uma página no relatório como se fosse apresentada diretamente ao cliente.

---

## 🗂️ Estrutura do Projeto
- `relatorio.pbix` → Arquivo do Power BI com os visuais criados.
- `README.md` → Explicação do projeto e contexto.

---

## 📊 Visuais Criados
1. **Visão por Categorias**  
   - Parâmetro configurado para alternar entre diferentes categorias (ex.: produto, região, segmento).  
   - Permite ao usuário explorar os dados de acordo com diferentes dimensões.

2. **Visão por Valores**  
   - Parâmetro configurado para alternar entre métricas como **Profit**, **Sales**, ou outras medidas relevantes.  
   - Facilita a análise comparativa de indicadores financeiros e operacionais.

---

## 📖 Storytelling
A página criada no relatório segue uma narrativa voltada para o cliente:
- **Introdução**: contexto do negócio e objetivo da análise.
- **Visão por Categorias**: mostra como diferentes segmentos impactam os resultados.
- **Visão por Valores**: evidencia métricas financeiras e operacionais, destacando oportunidades e riscos.
- **Conclusão**: insights principais e recomendações baseadas nos dados.

---

## 🛠️ Tecnologias Utilizadas
- **Power BI**
- Parâmetros de campos
- Técnicas de storytelling em dashboards

---

## 🚀 Como Reproduzir
1. Abra o arquivo `relatorio.pbix` no Power BI.
2. Explore os parâmetros configurados para alternar entre categorias e valores.
3. Navegue pela página de storytelling para visualizar a narrativa construída.
