## 📖 Sobre o Desafio

Este projeto faz parte do bootcamp **"Lupo - Primeiros Passos com Inteligência Artificial"** oferecido pela [DIO (Digital Innovation One)](https://www.dio.me/).

O objetivo é desenvolver um **Copiloto de Vendas com IA** projetado para apoiar profissionais comerciais em interações reais com clientes em lojas físicas. A solução utiliza inteligência artificial para estruturar pitchs de vendas, responder objeções, organizar informações sobre produtos e orientar follow-ups.

---

## 🎯 Objetivo do Projeto

Criar uma solução prática que conecta **tecnologia e estratégia comercial** para:

| Meta | Descrição |
|------|-----------|
| 🎓 **Estruturar pitchs** | Treinar e aprimorar discursos de vendas eficazes |
| 🤝 **Responder objeções** | Preparar respostas para objections comuns de clientes |
| 📦 **Organizar produtos** | Manter informações atualizadas sobre catalogo e diferenciais |
| 📞 **Orientar follow-ups** | Definir estrategias de acompanhamento pós-venda |
| 📈 **Aumentar produtividade** | Reduzir tempo de preparação e aumentar assertividade |

---

## 💡 Conceito Central

> **Um assistente virtual que transforma dados de clientes e produtos em orientações práticas para vendedores**, permitindo que profissionais de vendas tomem melhores decisões em tempo real durante o atendimento.

## 🚀 Como Utilizar

### 1. Configure o Contexto
Edite o `prompt.md` com:
- Informações da loja (segmento, promocoes, metas)
- Dados do produto em destaque
- Perfil do cliente atual

### 2. Selecione o Comando
| Comando | Quando usar |
|---------|-------------|
| `pitch` | Para gerar discurso de vendas personalizado |
| `objeção` | Para tratar resistencia do cliente |
| `comparar` | Para destacar diferenciais vs concorrência |
| `fechar` | Para scripting de fechamento |
| `followup` | Para estratégia pós-atendimento |

### 3. Execute no Copiloto
Inicie conversa no ChatGPT/Claude/Anthropic com o conteúdo do `prompt.md` + comando desejado.
