# Dashboard de Vendas - Bootcamp Klabin (DIO)

## 📊 Sobre o Projeto
Este projeto foi desenvolvido como parte do Bootcamp **Klabin - Excel e Power BI Dashboards 2026** na plataforma DIO.  
O objetivo é transformar dados brutos em informações visuais claras e úteis, permitindo uma análise eficaz do desempenho de vendas.

## 📂 Estrutura do Repositório
- `base.xlsx`: Base de dados fornecida para o desafio.
- `dashboard_final.xlsx`: Arquivo Excel com o dashboard de vendas concluído.
- `README.md`: Explicação do projeto e instruções de reprodução.

## 🚀 Como Reproduzir
1. Baixe os arquivos deste repositório.
2. Abra o arquivo `dashboard_final.xlsx` no Excel.
3. Explore os gráficos e indicadores criados a partir da base de dados.

## 📈 Indicadores do Dashboard
- Vendas por produto
- Vendas por região
- Evolução temporal das vendas
- Principais KPIs de desempenho

## 🛠️ Ferramentas Utilizadas
- Microsoft Excel
- Tabelas Dinâmicas
- Gráficos Dinâmicos
- Formatação Condicional
