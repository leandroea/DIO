# Anotações e Aprendizados

Durante este desafio, os seguintes aprendizados foram observados:

1. **Interação com o Copiloto:** A criação guiada permite automação produtiva sem perder controle sobre o conteúdo.
2. **Uso do OpenAI:** Ferramentas baseadas em IA ajudam na consistência e estruturação das informações.
3. **Filtragem de Conteúdo:** A aplicação de filtros garante a geração ética e segura de textos.
4. **Design de Prompts:** A qualidade do prompt é determinante para a precisão do resultado.
5. **Documentação:** Manter registros claros é essencial para aprendizado contínuo.
