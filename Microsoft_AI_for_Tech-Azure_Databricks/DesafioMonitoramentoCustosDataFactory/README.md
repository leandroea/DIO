# ☁️ Projeto Azure Data Factory - Controle de Custos e Organização de Recursos

Este projeto apresenta uma visão prática do ambiente **Microsoft Azure**, utilizando uma conta gratuita de estudante.  
O foco está em configurar o **Azure Data Factory** e preparar o ambiente para **monitorar o uso e os custos dos recursos implantados**, aplicando boas práticas de organização e automação.

---

## 🎯 Objetivos do Projeto
- Configurar o **Azure Data Factory** em um ambiente de estudante.  
- Estruturar assinaturas e grupos de recursos de forma organizada.  
- Aplicar boas práticas de nomenclatura para facilitar a gestão.  
- Personalizar dashboards para monitoramento de métricas.  
- Criar alertas de custo para evitar gastos inesperados.  
- Demonstrar o uso de **ARM Templates** para infraestrutura como código.  
- Utilizar o **Azure Cloud Shell** para automações via linha de comando.  

---

## 🏗️ Etapas do Projeto

### 1. Estruturação de Recursos
- Criação de **assinaturas** e **grupos de recursos**.  
- Definição de **boas práticas de nomenclatura** para padronização.  

### 2. Configuração do Azure Data Factory
- Criação e configuração do **Data Factory**.  
- Integração com outros serviços do Azure.  

### 3. Monitoramento e Custos
- Personalização de **dashboards** no portal do Azure.  
- Configuração de **métricas de uso** e **alertas de custo**.  

### 4. Infraestrutura como Código
- Criação de **ARM Templates** para provisionamento automatizado.  
- Execução de automações via **Azure Cloud Shell**.  

---

## ⚙️ Tecnologias Utilizadas
- **Microsoft Azure**  
- **Azure Data Factory**  
- **Azure Resource Manager (ARM Templates)**  
- **Azure Cloud Shell**  
- **Dashboards e métricas do Azure Monitor**  

---

## 🚀 Como Reproduzir
1. Crie uma conta gratuita de estudante no [Azure](https://azure.microsoft.com/free/students/).  
2. Configure uma assinatura e crie grupos de recursos.  
3. Implemente o **Azure Data Factory**.  
4. Personalize dashboards e configure alertas de custo.  
5. Utilize os **ARM Templates** e scripts disponíveis neste repositório para automação.  

---

## 📌 Benefícios Esperados
- Melhor **organização de recursos** no ambiente Azure.  
- Controle eficiente de **custos e consumo**.  
- Automação de tarefas repetitivas com **Cloud Shell**.  
- Documentação clara e prática para replicação do projeto.
