# 📘 Projeto Azure Databricks - Versionamento e Organização de Notebooks

Este projeto demonstra como utilizar o **Azure Databricks** para estruturar, versionar e organizar notebooks em ambientes de dados.  
A proposta inclui desde a criação de clusters até a automação de esteiras de CI/CD com **Azure DevOps**, promovendo uma abordagem colaborativa, segura e escalável para projetos de **engenharia de dados**, **análise** e **machine learning**.

---

## 🎯 Objetivos do Projeto

- Criar e configurar clusters no Azure Databricks.
- Importar arquivos e executar notebooks com auxílio de IA.
- Integrar o ambiente com **Azure DevOps** para versionamento e automação.
- Utilizar IA para gerar código em **Python** e **Spark**.
- Criar notebooks interativos com filtros, visualizações e explicações.
- Aplicar boas práticas de organização, exportação e reaproveitamento.
- Explorar recursos do **Microsoft Learn** para aprendizado guiado.

---

## 🏗️ Etapas do Projeto

### 1. Configuração Inicial
- Criação de workspace no Azure Databricks.
- Provisionamento de clusters com configurações otimizadas.

### 2. Importação e Execução de Notebooks
- Upload de arquivos `.csv`, `.json` e `.parquet`.
- Criação de notebooks com auxílio da IA integrada.
- Geração de código para leitura, transformação e visualização de dados.

### 3. Integração com Azure DevOps
- Conexão com repositório Git.
- Versionamento automático de notebooks.
- Configuração de pipelines de CI/CD para automação de deploy.

### 4. Boas Práticas e Organização
- Padronização de nomenclatura e estrutura de diretórios.
- Exportação de notebooks em formatos reutilizáveis.
- Compartilhamento seguro entre equipes.

### 5. Aprendizado Guiado
- Utilização de trilhas do **Microsoft Learn**.
- Aplicação de exercícios práticos e roteiros de estudo.

---

## ⚙️ Tecnologias Utilizadas

- **Azure Databricks**

- **Python**
- **Azure DevOps**

- **Microsoft Learn**

---

## 🚀 Como Reproduzir

1. Crie uma conta gratuita no [Azure para Estudantes](https://azure.microsoft.com/free/students/).
2. Acesse o portal e crie um workspace do Azure Databricks.
3. Configure um cluster e importe os notebooks disponíveis neste repositório.
4. Conecte seu repositório Git via Azure DevOps.
5. Execute os notebooks e explore os recursos de IA para geração de código.
