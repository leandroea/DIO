# 📚 Repositório de Cursos e Projetos - DIO

Este repositório reúne todos os cursos que realizo na **DIO (Digital Innovation One)**, organizados em pastas correspondentes a cada trilha ou bootcamp.  
Dentro de cada pasta de curso, estão os projetos desenvolvidos durante os desafios práticos e atividades propostas.

---

## 🚀 Sobre a DIO

A **Digital Innovation One (DIO)** é hoje uma das maiores plataformas de educação em tecnologia da América Latina, com mais de **1.750 cursos, bootcamps imersivos e uma comunidade ativa**.  
A proposta da DIO é oferecer **formação prática e imersiva**, cocriada com grandes empresas como **Microsoft, iFood, Carrefour, Bradesco, Santander, Klabin**, entre outras.  

Os bootcamps e cursos da DIO são voltados para preparar profissionais para os desafios reais do mercado de tecnologia, com:
- **Projetos práticos** aplicados a cenários reais.
- **Desafios técnicos** que simulam ambientes
